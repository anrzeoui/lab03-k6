## 2. SLO

| Scenario | SLI | Босго | Цонх / нөхцөл |
|---|---|---|---|
| Performance | `/cart/add` latency | p95 < 15 ms | 20 VU, 1 минут |
| Reliability | `/pay` error rate | < 8% | 20 VU, 1 минут |
| Availability | Амжилттай хүсэлтийн хувь | ≥ 90% | 2 минут, 10 секундийн зогсолт |

### SLO сонгосон үндэслэл

Performance baseline тестээр `/cart/add` endpoint-ийн p95 latency **7.03 ms** гарсан тул бодит хэмжилтэд тулгуурлан **p95 < 15 ms** босго сонгосон.

`/pay` endpoint нь зориудаар ойролцоогоор 5% алдаа үүсгэдэг тул Reliability SLO-г **error rate < 8%** гэж сонгосон.

Availability SLO-г **≥ 90%** гэж сонгосон бөгөөд 2 минутын туршилтын үед богино хугацааны серверийн зогсолтыг зөвшөөрөх боломжтой гэж үзсэн.

### Error Budget

Availability SLO = 90%

Error budget = 100% - 90% = **10%**

2 минут = 120 секунд.

120 × 0.10 = **12 секунд**

Иймээс хугацаагаар тооцсон error budget нь **12 секунд** байна.
