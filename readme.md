## 1. Quality Scenarios

### 1.1 Performance Scenario

| Хэсэг | Тайлбар |
|---|---|
| Тойм | Сагсанд бүтээгдэхүүн нэмэх үйлдлийн хурдыг шалгана |
| Системийн төлөв | Сервер хэвийн ажиллаж байна |
| Орчны төлөв | 20 VU тогтмол ачаалалтай |
| Гадаад өдөөлт | Хэрэглэгч `/cart/add` endpoint руу хүсэлт илгээнэ |
| Шаардлагатай хариу | Сервер хүсэлтийг амжилттай боловсруулж HTTP 200 буцаана |
| Хэмжүүр | `/cart/add` хүсэлтийн p95 latency тогтоосон босгоос бага байна |

### 1.2 Reliability Scenario

| Хэсэг | Тайлбар |
|---|---|
| Тойм | Төлбөрийн үйлдлийн найдвартай байдлыг шалгана |
| Системийн төлөв | Сервер хэвийн ажиллаж байна |
| Орчны төлөв | 20 VU тогтмол ачаалалтай |
| Гадаад өдөөлт | Хэрэглэгч `/pay` endpoint руу төлбөрийн хүсэлт илгээнэ |
| Шаардлагатай хариу | Төлбөрийн хүсэлтүүдийн ихэнхийг сервер амжилттай боловсруулна |
| Хэмжүүр | `/pay` endpoint-ийн error rate тогтоосон босгоос бага байна |

### 1.3 Availability Scenario

| Хэсэг | Тайлбар |
|---|---|
| Тойм | Сервер түр зогсоод дахин асах үеийн хүртээмжийг шалгана |
| Системийн төлөв | Сервер эхэндээ хэвийн ажиллаж байна |
| Орчны төлөв | 2 минутын турш load test ажиллана |
| Гадаад өдөөлт | Серверийг зориудаар 10 секунд зогсоогоод дахин асаана |
| Шаардлагатай хариу | Сервер дахин ассаны дараа хүсэлтүүдийг хэвийн боловсруулна |
| Хэмжүүр | Амжилттай хүсэлтийн хувь болон серверийн сэргэх хугацааг хэмжинэ |
